=============
futhark-metal
=============

SYNOPSIS
========

futhark metal [options...] <program.fut>

DESCRIPTION
===========


``futhark metal`` translates a Futhark program to Objective-C code
invoking Metal kernels, and either compiles that code with a C
compiler to an executable binary program, or produces a ``.h`` and
``.c`` file that can be linked with other code. The standard Futhark
optimisation pipeline is used.  The Metal backend requires macOS 15 or
newer.

The generated ``.c`` file must be compiled as Objective-C without
automatic reference counting, and linked with the Metal and Foundation
frameworks.  ``futhark metal`` passes ``-ObjC -fno-objc-arc -framework
Metal -framework Foundation`` to the C compiler.  If using
``--library``, you will need to do the same when compiling and linking
the final binary.  The generated header file is plain C.

Apple GPUs do not support double precision floating point, nor 64-bit
atomic operations.  Programs that need these in GPU code cannot be
compiled with ``futhark metal``.

OPTIONS
=======

Accepts the same options as :ref:`futhark-c(1)`.

ENVIRONMENT VARIABLES
=====================

``CC``

  The C compiler used to compile the program.  Defaults to ``cc`` if
  unset.

``CFLAGS``

  Space-separated list of options passed to the C compiler.  Defaults
  to ``-O -std=c99`` if unset.

EXECUTABLE OPTIONS
==================

Generated executables accept the same options as those generated by
:ref:`futhark-c(1)`.  For commonality, the options use OpenCL
nomenclature ("group" instead of "thread block").

The following additional options are accepted.

-d, --device=NAME

  Use the first device whose name contains the given string.  The
  special string ``#k``, where ``k`` is an integer, can be used to
  pick the *k*-th device, numbered from zero.

--default-group-size=INT

  The default size of thread blocks that are launched.  Capped to the
  hardware limit if necessary.

--default-num-groups=INT

  The default number of thread blocks that are launched.

--default-threshold=INT

  The default parallelism threshold used for comparisons when
  selecting between code versions generated by incremental flattening.
  Intuitively, the amount of parallelism needed to saturate the GPU.

--default-tile-size=INT

  The default tile size used when performing two-dimensional tiling
  (the workgroup size will be the square of the tile size).

--dump-metal=FILE

  Don't run the program, but instead dump the embedded Metal program
  to the indicated file.  Useful if you want to see what is actually
  being executed.

--load-metal=FILE

  Instead of using the embedded Metal program, load it from the
  indicated file.

--build-option=OPT

  Add a preprocessor definition, of the form ``-DNAME`` or
  ``-DNAME=VALUE``, when compiling the Metal program.

--list-devices

  List all Metal devices available on the system.
